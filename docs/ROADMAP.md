# нуглянь — разработка

Обязательное ограничение: бесплатные тарифы, без платных подписок. Не менять существующий дизайн и не сокращать авторские заметки.

## Реализовано на Supabase
- PostgreSQL: приватные записи, отдельные публичные снимки, список администраторов, метаданные и бюджет запросов.
- Серверная проверка администратора, безопасный импорт, контроль версий и публикация.
- Проверен цикл импорта, публикации, изменения и снятия с публикации в откатываемой транзакции.
- Проект: https://supabase.com/dashboard/project/ezycipkttvaoasftqpug
- Действующая версия: https://kinoteka-veroniki.waxencream256.chatgpt.site

## В работе
- Серверная Edge Function кино API, тест реального ответа, лимит запросов. Токен хранится только в секретах Supabase. Демо-тариф: проверить разрешение на публичное использование.
- Интеграция интерфейса с Supabase Auth и каталогом.
- Получение оригинального исходного frontend и полного актуального экспорта. Без них не заменять существующий сайт и не импортировать пересказанные заметки.

## Далее
- Миграция данных с проверкой полноты и идентичности текста.
- Умный поиск и рекомендации без платного AI API.
- Ссылки на просмотр, iOS-адаптация, QA/UAT.
- CI/CD и бесплатный хостинг: GitHub Pages после публичности репозитория либо другой бесплатный вариант.

## Безопасность
Не коммитить секретные ключи, пароли, приватные экспортированные карточки и .env. Публичный frontend использует только publishable key и RLS.
